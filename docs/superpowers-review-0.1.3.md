# 0.1.3 review checklist

Temporary review checklist for the release branch. Remove before merge.

- Save dialogs do not rerender during the request and preserve dialog scroll state.
- Optional power/temperature sensors normalize empty/null values to no sensor.
- New battery capacity has no implicit 1000 mAh default and is required explicitly.
- Optional rest time remains unset when blank.
- Nominal voltage label explicitly identifies output voltage.
- Battery and charging-setup images support URL/local path and direct JPEG/PNG/WebP upload.
- Upload paths are generated by the backend; user filenames are never used as filesystem paths.
- Setup images persist in the data model and appear in the setup overview.
