# Version 0.4.2 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Execute the user-approved scope inline.

**Goal:** retain all measurements, reliably close and expose every attempt, and separate evidence from charge estimates.
**Architecture:** SQLite immutable raw archive plus derived current checkpoints and metadata; pure interval/regime analysis modules; existing manager/UI adapted without replacing charger safety.
**Tech Stack:** Python stdlib SQLite/asyncio, Home Assistant, JavaScript custom elements, unittest and Node test.
**Spec:** ../specs/2026-09-24-v042-design.md

## Global Constraints
- No automatic loss of observations or operations; no destructive data API.
- All new versions 0.4.2; compatible reading of prior schema 4.
- No nominal-capacity forcing, assumed physical freshness or automatic acceptance of estimates.
- Keep checked switch-off, timeout, power, temperature and fixed-source safeguards.
- No user measurement export or identifying configuration in public fixtures.

## Review Focus
- Storage failure after shutdown: don't claim saved or discard the last in-memory trace.
- Restart/duplicate commands: exactly one visible attempt and deterministic migration.
- Unchanged HA reports vs cached polling: provenance and energy cannot be invented.
- Retrospective idle/endpoint edits: original raw hashes and prior analyses must survive.
- Pulsed tail or resumed load: avoid using time/sample-count or nominal-energy shortcuts.
