# Changelog

## 0.0.1

Initial development version.

- Added Home Assistant UI config flow.
- Added smart-plug, energy-sensor and optional power-sensor configuration.
- Added persistent battery-type library with image, capacity, technology and form factor.
- Added separate calibration histories by battery type and quantity.
- Added median calibration value calculation.
- Added manual calibration start/finish workflow.
- Added automatic storage-charge cutoff by calibrated Wh target.
- Added persistent active-session state across Home Assistant restarts.
- Added energy-sensor-unavailable shutdown.
- Added maximum-session safety timeout.
- Added German and English translations.
